# 🔒 Privacy Policy — StickerToSprite3Bot

> This bot converts Telegram stickers into `.sprite3` files for Scratch/mBlock.

---

## 📥 What We Collect

- **Basic Telegram account information** — to identify who sent each request
- **Sticker details** — pack name and sticker ID, used to process and cache conversions
- **Conversion metadata** — file size, frame count, success/failure status

## 🚫 What We Do NOT Collect

- Your messages, contacts, or any other personal data
- Payment information — *this bot is completely free*

---

## ⚙️ How Data Is Used

- Solely to process your sticker conversion and maintain a usage log for the bot owner
- Converted files are **cached** to avoid reprocessing the same sticker repeatedly

## 🗄️ Data Storage

- Usage logs are stored in a **private Google Sheet**, accessible only to the bot owner
- Generated files are stored via **Telegram's own file system**
